# Maintained corrected D3 executable profile

This profile builds the actual unchanged M3.1 runtime, B1/B2/B3 and smoke main.
It is an uncommitted working-tree source baseline, not a clean Git release.
Historical hardware evidence belongs to a different exact BIN identity. A new
build is never automatically hardware-validated, even if its bytes match.

This bounded D3 fork preserves the D2 executable and all14 negative audit gates.
D2 tools/manifests remain untouched. The new scripts own their configuration;
only the pinned pure ELF/map parsers from runtime audit.py are imported.
No archive or historical /tmp build is a required target-build input.

## Contract

Source paths derive from tools/profile.py; CWD is irrelevant. Twelve objects,
MC68010 flags and both diagnostic defines, termios renames, unchanged link.ld,
explicit machine.o extraction and libc/libgcc grouping match the D3 record.
No whole librosco link, legacy FAT/SD provider, new syscall layer or storage write.
Console _write_r is allowed. TRAP13 selectors0/1/2/4, CMD9, exact aligned wrapper
bodies and48-byte snapshot remain mandatory. No production source is modified.

Tools must match approved hashes, GCC13.3.1 and binutils2.42. Library identities
are role-based rather than tied to an installation prefix. Toolchain headers
are pinned relative to gcc/newlib include roots. Unknown compiler dependencies
fail closed. Injection environment variables are rejected, not silently used.

## Explicit operations (only when separately authorized)

Set PROFILE to this directory; supply a NEW absolute /tmp build directory:

    python3 "$PROFILE/tools/build.py" --build "$BUILD" compile
    python3 "$PROFILE/tools/build.py" --build "$BUILD" link
    python3 "$PROFILE/tools/build.py" --build "$BUILD" binary
    python3 "$PROFILE/tools/build.py" --build "$BUILD" inspect
    python3 "$PROFILE/tools/audit.py" "$BUILD" --machine-only
    python3 "$PROFILE/tools/audit.py" "$BUILD"
    python3 "$PROFILE/tools/negative_audit.py" "$BUILD"

Optional --toolchain-bin DIR selects the approved toolchain explicitly for build
commands. Audit uses the recorded verified tools. Paths must not contain spaces,
newlines or commas. Outputs stay in BUILD; compile refuses ANY existing directory.
Subsequent actions require the exact source/profile marker and unchanged objects.
No automatic deletion, rebuilding, archive discovery, source-pin regeneration,
network, hardware or serial operation. Failed commands leave evidence in BUILD.
Artifact basename is m31-csd-v2fix-rebuild-diag. Commands/output hashes and actual
resolved toolchain paths are recorded in build-record.json; .su files accompany
objects. Historical source manifests are evidence only, not current verification.

SHA256SUMS covers this directory excluding itself; PROVENANCE.json pins external
project inputs, compiler/header/library identities and member allowlists. Pins
are explicitly reviewed at implementation time, NEVER regenerated by build.
Output records do not enter the input manifest; no self-referential hash cycle.

## Host validation and historical fixture

Existing b3_csd_diagnostic/tools/validate_host.py provides normal/ASan/UBSan,
OFF/ON real-backend and application regressions with external outputs.
Runtime tests require: tests/run.py BUILD --historical-runtime-bin PATH.
The historical BIN must be44980B, SHA256
066e667d849623ac682c8153542af1f688209f28c9f09a0bedaafba6943ebeb5.
It is not the D3 SD/FAT BIN and is never replaced by a fresh runtime build.
Missing/wrong fixture BLOCKS the full runtime validation before compilation.
Tests receive M31_HISTORICAL_RUNTIME_BIN. LSan remains NOT VERIFIED when disabled.
Profile tests require M31_PROFILE_TEST_OUTPUT pointing to a fresh external /tmp
path; run tests/test_profile.py with PYTHONDONTWRITEBYTECODE=1.

## Audit interpretation / limits

Machine audit exit0 is automatic static PASS, not hardware approval. Full audit
requires manual-review.json tied to THIS ELF/BIN with reviewer/notes/checks.
Exit3 means CONDITIONAL; exit2 is audit failure. A template is not acceptance.
No complete firmware/IRQ/libc stack bound, deployed-ROM identity, independent
physical CSD CRC, full manual library instruction review or broad card/FAT
compatibility is established by build flags or past smoke success.
Negative tests mutate ONLY temporary copies of a positive machine-audited build;
each of14 must fail for its intended reason, not missing manual review alone.

The approved historical reference BIN is62044B SHA256
d0110563cf819b6023d3b5b31883c7eb0aa222640cbdfc39978e5af233f10c0f,
CRC0xEBB863C5. New ELF/MAP may differ due to debug/build paths. Any new BIN
identity is recorded and differences explained, never forced by flag changes.
The permanent archive is optional historical comparison evidence, not a build
input. Independent Git-checkout validation remains pending until sources are
committed; dirty-tree tests must never be described as that validation.
All new hardware runs, commits and pushes require separate authorization.
